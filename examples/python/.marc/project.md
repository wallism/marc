# Synthetic Python consumer

This example assumes a Python project with pytest and existing GitHub Actions jobs called `Tests` and `Security`. Configure their real commands and artifact contents during setup; this example does not provide that pipeline. No private infrastructure or credentials are needed to resolve these settings.

Use the project's documented Python test/type/lint and dependency-audit evidence. Dependency/build manifest changes remain sensitive because the bundled classifiers do not classify Python dependency changes. No browser runtime is supplied: if a change requires browser evidence, obtain confirmed project guidance and an authorized isolated runtime or report the missing prerequisite.

The example uses report-only mode. Replace the producer identity and confirm all settings before an operational run. No npm vulnerability deferrals or historical secret exceptions apply.
